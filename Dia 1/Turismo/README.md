O usuário digita rotamineira.com.br. O DNS resolve o domínio para o 
endereço IP do servidor. O navegador estabelece uma conexão e envia uma requisição HTTP/HTTPS para a página inicial. O servidor localiza index.html e envia uma resposta com o HTML e o status 200 (OK), se tudo ocorrer corretamente. O navegador interpreta o HTML e exibe a página.

Domínio e contatos utilizados como exemplos didáticos.
