
# Atividade 9 - Raio X de um site

## Site escolhido

- Nome: Pizzaria Nápoles
- Cidade: Cambuí - MG
- Site: https://www.restaurantenapoles.com.br/

## Investigação

Escolhi o site da Pizzaria Nápoles e usei o
DevTools para analisar como ele foi feito.

Percebi que o site utiliza WordPress e tem
várias tags div e section.

O menu está dentro de uma section com o id
menu3-0.

O conteúdo da página está dentro de uma div
com o id page.

O rodapé também utiliza uma section em vez
da tag footer.

## Quantidade de tags

| Tag | Quantidade |
|---|---:|
| h1 | 1 |
| header | 1 |
| nav | 1 |
| main | 1 |
| footer | 1 |
| div | 181 
## Uso de div

A div com o id page poderia ser trocada por
main, caso tenha apenas o conteúdo principal
do site.

## O que eu mudei

- Usei header para o cabeçalho.
- Usei nav para o menu.
- Usei main para o conteúdo principal.
- Separei os assuntos usando section.
- Usei footer para o rodapé.
- Usei address para o endereço.
- Organizei os títulos.
- Coloquei ids nas seções.

Com essas mudanças, o código ficou mais
organizado e fácil de entender.
